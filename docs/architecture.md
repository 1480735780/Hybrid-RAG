## 4. 技术选型原因

### 4.1 Embedding: BGE-M3

- 多语言支持（中英文）
- 多粒度表征（dense, sparse, colbert）
- 高性能，适合运维文档

### 4.2 向量数据库: ChromaDB/Milvus

- ChromaDB: 开发环境，轻量级，易于部署
- Milvus: 生产环境，高性能，可扩展

### 4.3 Rerank: BGE-Reranker

- Cross-encoder 架构，精度高
- 支持中英文
- 与 BGE-M3 配合良好

### 4.4 BM25: rank-bm25

- 经典算法，对关键词匹配效果好
- 支持中文分词（jieba）
- 轻量级，无额外依赖

### 4.5 LLM: Qwen/GPT-4

- Qwen: 国产模型，中文理解好，成本低
- GPT-4: 通用能力强，适合复杂推理
- 支持多种 LLM 灵活切换

## 6. 扩展性设计

### 6.1 模块化设计

- 每个模块独立，可单独替换
- 接口标准化，易于扩展
- 配置驱动，灵活调整

### 6.2 LLM 扩展

```python
# 支持多种 LLM
LLM_PROVIDER=openai    # OpenAI
LLM_PROVIDER=dashscope # 阿里云
LLM_PROVIDER=local     # 本地模型
```

### 6.3 向量数据库扩展

```python
# 支持多种向量数据库
VECTOR_STORE_TYPE=chroma  # ChromaDB
VECTOR_STORE_TYPE=milvus  # Milvus
VECTOR_STORE_TYPE=qdrant  # Qdrant (计划中)
```

### 6.4 文档格式扩展

```python
# 支持多种文档格式
parsers = {
    ".pdf": PDFParser(),
    ".docx": DocxParser(),
    ".txt": TextParser(),
    ".md": MarkdownParser(),
    ".log": LogParser(),
    # 可扩展更多格式
}
```
